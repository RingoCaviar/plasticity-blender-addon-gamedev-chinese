# Plasticity Blender Addon GameDev 中文版

这是 `plasticity-blender-addon-gamedev` 的简体中文分支，面向使用 Blender 中文界面的用户。

## 使用方法

1. 将仓库目录压缩为 ZIP，或下载本分支的 ZIP。
2. 在 Blender 中打开“编辑 → 偏好设置 → 插件”，选择“从磁盘安装”，然后选择 ZIP。
3. 启用 **Plasticity Blender Addon Gamedev**。
4. 在“偏好设置 → 界面 → 翻译”中启用翻译，并将语言设为“简体中文”。
5. 在 3D 视图右侧边栏中打开 **Plasticity** 标签页。

中文词典通过 Blender 原生翻译 API 注册，不会改动操作符 ID、属性 ID、Plasticity 通信协议或已保存场景中的数据。未开启 Blender 界面翻译时，插件仍显示原始英文。

## 汉化范围

- 连接、刷新、实时链接与发送到 Plasticity
- 重新细分及预设
- Plasticity 面选择、边标记、实时扩展和缝合边工具
- UV、材质与检查纹理工作流
- 网格工具及 FBX/OBJ 导入导出
- 常用选项说明与工具提示
